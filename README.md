# LAB3 — Automação MLOps com CI/CD e GitHub Actions
Este laboratório demonstra como automatizar etapas de um pipeline
MLOps utilizando GitHub Actions.

## Fluxo
Código
→ Commit
→ GitHub Actions
→ Instalação
→ Treinamento
→ Avaliação
→ Quality Gate
→ PASS / FAIL

## Tecnologias
- Python
- Scikit-learn
- GitHub
- GitHub Actions

## Objetivo
Demonstrar como mudanças no código podem iniciar automaticamente
um pipeline de Machine Learning com critérios de aprovação.

Laboratório desenvolvido exclusivamente para fins educacionais.
